# إرسال عدد صحيفة الشرق الأوسط اليومي عبر Telegram

مشروع يقوم تلقائيًا كل يوم بتحميل النسخة الرقمية (PDF) من صحيفة الشرق
الأوسط، وإرسالها عبر بوت Telegram، وذلك عبر GitHub Actions دون الحاجة
لأي جهاز يعمل باستمرار.

## آلية العمل

1. يُحسب رقم عدد اليوم اعتمادًا على عدد مرجعي معروف (العدد 17457 بتاريخ
   2026-09-14) وإضافة فرق الأيام إليه.
2. يحاول السكربت أولًا تحميل الملف مباشرة عبر الرابط الثابت الذي تحقق
   منه فعليًا (وهو نفس الرابط الذي ينتهي إليه زر "Download" في صفحة
   القارئ). هذه الطريقة سريعة ولا تحتاج متصفحًا.
3. في حال فشلت هذه الطريقة (مثلًا بسبب تغيير مستقبلي في بنية الموقع)،
   يلجأ السكربت تلقائيًا إلى خطة بديلة باستخدام Playwright: يفتح صفحة
   العدد، يضغط على زر "Download" في الشريط السفلي، ثم يضغط على رابط
   "Full Publication - PDF" داخل النافذة المنبثقة، ويلتقط الملف الناتج.
4. يُرسل الملف الناتج عبر Telegram Bot API إلى المحادثة المحددة.

> ملاحظة تقنية: عند فحص صفحة القارئ فعليًا بالمتصفح، تبيّن أن الموقع لا
> يستخدم زر قائمة منفصل بمعرف `toolbar-menu-button`، بل يعرض زر
> "Download" مباشرة ضمن شريط الأدوات السفلي (`class="bottom-toolbar"`)،
> والضغط عليه يفتح نافذة منبثقة تحتوي رابط "Full Publication" الذي ينفّذ
> التحميل الفعلي. تم بناء السكربت على أساس هذا السلوك الحقيقي بعد
> التحقق منه مباشرة، وليس على الوصف الافتراضي.

## الملفات

- `download_and_send.py`: السكربت الرئيسي (تحميل + إرسال).
- `requirements.txt`: الاعتماديات (`playwright`, `requests`).
- `.github/workflows/daily.yml`: جدولة التشغيل اليومي عبر GitHub Actions.

## الخطوات المطلوبة منك لتفعيل المشروع

### 1. إنشاء بوت Telegram والحصول على التوكن و chat_id

1. افتح محادثة مع [@BotFather](https://t.me/BotFather) على Telegram.
2. أرسل الأمر `/newbot` واتبع التعليمات (اختيار اسم البوت ومعرّفه).
3. سيعطيك BotFather **توكن البوت** (Bot Token) بصيغة شبيهة بـ:
   `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`. احتفظ به سرًا.
4. لمعرفة **chat_id**:
   - إذا كنت تريد إرسال الملف إلى محادثتك الشخصية: ابدأ محادثة مع بوتك
     الجديد وأرسل له أي رسالة (مثلًا "مرحبًا")، ثم افتح الرابط التالي في
     المتصفح بعد استبدال `<TOKEN>` بتوكن بوتك:
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
     وابحث عن الحقل `"chat":{"id": ...}` في الرد؛ هذا الرقم هو chat_id.
   - إذا كنت تريد الإرسال إلى قناة أو مجموعة: أضف البوت إليها كمشرف،
     ثم أرسل رسالة في القناة/المجموعة واستخدم نفس الرابط أعلاه لمعرفة
     chat_id الخاص بها (عادة ما يبدأ برقم سالب للمجموعات والقنوات).

### 2. إضافة القيمتين كأسرار (Secrets) في GitHub

1. من صفحة المستودع على GitHub، اذهب إلى:
   `Settings` → `Secrets and variables` → `Actions`.
2. اضغط `New repository secret` وأضف:
   - الاسم: `TELEGRAM_BOT_TOKEN` — القيمة: توكن البوت.
3. كرر الخطوة وأضف:
   - الاسم: `TELEGRAM_CHAT_ID` — القيمة: معرّف المحادثة (chat_id).

### 3. تجربة السكربت محليًا قبل الاعتماد على الجدولة التلقائية

```bash
pip install -r requirements.txt
playwright install --with-deps chromium   # مطلوب فقط للخطة البديلة

export TELEGRAM_BOT_TOKEN="ضع_التوكن_هنا"
export TELEGRAM_CHAT_ID="ضع_chat_id_هنا"

python download_and_send.py
```

يمكنك أيضًا تجربة عدد محدد بدلًا من عدد اليوم عبر:

```bash
python download_and_send.py --issue 17457
```

### 4. تجربة الجدولة عبر GitHub Actions يدويًا

بعد رفع المشروع وإضافة الأسرار، اذهب إلى تبويب `Actions` في المستودع،
اختر workflow باسم "Daily Asharq Al-Awsat PDF to Telegram"، ثم اضغط
`Run workflow` لتشغيله يدويًا والتأكد من نجاحه قبل انتظار الجدولة
التلقائية.

بعد التأكد من نجاح التشغيل اليدوي، سيعمل المشروع تلقائيًا كل يوم الساعة
1:30 صباحًا بتوقيت السعودية دون أي تدخل إضافي.
